# ДЭ 2026 · Специалист по информационным системам

Сайт подготовки по КОД 09.02.07-5-2026, базовый уровень: 5 модулей, 150 минут, 50 баллов.

Разбор каждого модуля: действия, SQL/C# целиком, пояснения, контроль результата. Два стека: C# Windows Forms + MySQL (phpMyAdmin) и C# Windows Forms + PostgreSQL (pgAdmin). Таблицы и связи можно создавать через интерфейс или SQL; настройки всех 11 таблиц приведены в разборе. ER-диаграмма содержит каждое поле в отдельной строке.

«Моя тренировка» использует исходные задания КОД. «Пробный экзамен» содержит 30 учебных вариантов по номеру в списке группы. У каждого — пять связанных заданий, свои документы, JSON контрагентов, материалы M4, отдельный таймер и отметки. Варианты просматриваются на сайте и скачиваются по одному или общим архивом. Генератор — `scripts/mock-variants.mjs`; готовые файлы — `site/mock/`. Сохранены локальные таймеры и тёмная тема.

## Открыть и собрать

Готовый сайт — `site/index.html`. Для HTTP-просмотра:

```sh
npm run build
npm run preview
```

Открыть адрес, напечатанный сервером (по умолчанию http://127.0.0.1:4190). Нужен Node.js 22+. Для работы сайта внешние сервисы не нужны. Перед запуском тестов выполните npm ci: для проверки разметки используется linkedom.

## Занятие и презентационный разбор

В верхнем меню доступны «Настройка перед занятием», «Как пользоваться» и переключатель светлой / тёмной темы. Профиль преподавателя содержит ФИО, должность, подразделение, учебное заведение и ссылку на материалы; его можно сохранить в браузере и перенести через JSON.

В каждом разборе кнопка «Презентация разбора» открывает слайды выбранного модуля и СУБД с титулом, материалами, содержанием, клавиатурным управлением и полноэкранным показом. Позиция слайдов сохраняется. [Инструкция по всем действиям](docs/USER_GUIDE.md).

## C#-примеры

`examples/mysql/Polesie.csproj`, `examples/postgresql/Polesie.csproj` и общие исходники `examples/shared/`. Инструкция — `examples/README.md`. ZIP для скачивания собирается автоматически из этих же исходников. Требуется .NET Framework 4.8, Visual Studio и доступный сервер выбранной СУБД.

Подробные HTML-разборы находятся в `lessons/`. Полный код вставляется в них при сборке из файлов проекта — расхождения между объяснением и скачиваемым файлом исключаются для вставленных фрагментов.

В `materials/` — только исходные приложения 2026 базового уровня, официальный PDF, ER-диаграмма и снимки C#-форм. Числа в учебной базе — отдельный пример; исходный JSON импортирован без изменения значений.

## Проверки и источники

`npm test` проверяет состав сайта, режимы и файлы. `docs/integration-results.json` — результаты выполнения C# на MySQL 8.4.0 и PostgreSQL 18. `tests/integration.mjs` относится к изолированной локальной среде разработчика; не запускайте его на рабочей базе. Основные проверки авторизации — `examples/shared/Checks.cs`.

Источники и точные версии репозиториев: `docs/sources.json`. Рабочие реквизиты, бинарники сборки и тестовые базы исключены из Git. Сайт не загружает решения студентов и не выставляет оценки.

Условия выбора ПО и результаты проверки обновлённых примеров: [docs/SOFTWARE.md](docs/SOFTWARE.md).
