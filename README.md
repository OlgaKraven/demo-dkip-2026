# ДЭ 2026 · Специалист по информационным системам

Сайт подготовки по КОД 09.02.07-5-2026, базовый уровень: 5 модулей, 150 минут, 50 баллов.

Разбор каждого модуля: действия, SQL/C# целиком, пояснения, контроль результата. Два стека: C# Windows Forms + MySQL и C# Windows Forms + PostgreSQL. Сохранены «Моя тренировка», «Пробный экзамен», локальные таймеры, заметки и тёмная тема.

## Открыть и собрать

Готовый сайт — `site/index.html`. Для HTTP-просмотра:

```sh
npm run build
npm run preview
```

Открыть адрес, напечатанный сервером (по умолчанию http://127.0.0.1:4190). Нужен Node.js 22+. У сайта нет зависимостей npm и внешних сервисов.

## Примеры

`examples/mysql/Polesie.csproj`, `examples/postgresql/Polesie.csproj` и общие исходники `examples/shared/`. Инструкция — `examples/README.md`. ZIP для скачивания собирается автоматически из этих же исходников. Требуется .NET Framework 4.8, Visual Studio и доступный сервер выбранной СУБД.

Подробные HTML-разборы находятся в `lessons/`. Полный код вставляется в них при сборке из файлов проекта — расхождения между объяснением и скачиваемым файлом исключаются для вставленных фрагментов.

В `materials/` — только исходные приложения 2026 базового уровня, официальный PDF, ER-диаграмма и снимки C#-форм. Числа в учебной базе — отдельный пример; исходный JSON импортирован без изменения значений.

## Проверки и источники

`npm test` проверяет состав сайта, режимы и файлы. `docs/integration-results.json` — результаты выполнения C# на MySQL 8.4.0 и PostgreSQL 18. `tests/integration.mjs` относится к изолированной локальной среде разработчика; не запускайте его на рабочей базе. Основные проверки авторизации — `examples/shared/Checks.cs`.

Источники и точные версии репозиториев: `docs/sources.json`. Рабочие реквизиты, бинарники сборки и тестовые базы исключены из Git. Сайт не загружает решения студентов и не выставляет оценки.
