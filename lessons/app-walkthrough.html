Окна приложения: куда нажимать

На снимках показан учебный пример «Полесье». Ориентируйтесь на названия кнопок и вкладок. Для своей программы используйте учётные записи и данные, которые создали сами.

Вход: логин, пароль и пазл

  1. Щёлкните поле «Логин». Введите свой логин. В готовом примере: admin.
  2. Щёлкните поле «Пароль». В готовом примере введите DemoAdmin!2026; для своей базы — пароль созданной учётной записи.
  3. Сравните картинку слева с четырьмя фрагментами справа. Нажмите один фрагмент, затем второй: они поменяются местами. Повторяйте, пока изображение не совпадёт с образцом. Начальное расположение каждый раз может отличаться.
  4. Нажмите «Войти». Ожидается сообщение «Вы успешно авторизовались», затем главное окно. При ошибке прочитайте сообщение; не повторяйте случайные попытки — третья ошибка блокирует учётную запись.

Заказчики: открыть список и загрузить JSON

  1. Войдите администратором. Нажмите вкладку «Заказчики» в верхнем левом углу.
  2. Нажмите «Импорт Заказчики.json». В открывшемся окне выберите исходный файл Заказчики.json, затем нажмите «Открыть».
  3. Ожидается сообщение «Обработано заказчиков: 6». Закройте его кнопкой OK и проверьте таблицу. В ранее пустой базе появятся шесть заказчиков.
  4. Нажмите «Обновить», чтобы перечитать данные. Сверьте названия, телефоны со знаком «+» и коды с ведущими нулями. Повторный импорт того же файла не должен добавлять дубли.

Стоимость: найти итог своего заказа

  1. Нажмите «Стоимость заказов» вверху окна.
  2. Найдите строку по номеру заказа и сравните сумму с ручным расчётом из модуля 3.
  3. Для набора 03-demo.sql ожидаются 371,00; 126,45; 183,95. Это контрольные числа учебного набора, а не ответы для исходного заказа из КИМ.
  4. Если ячейка итога пустая, проверьте наличие состава и цены материала на дату заказа. После исправления базы перейдите в «Заказчики» → «Обновить», затем снова откройте стоимость.

Новый пользователь: заполнить нижнюю панель

  1. Под администратором откройте «Пользователи».
  2. Нажмите «Новый пользователь» снизу слева. Проверьте, что поле логина очистилось.
  3. В поле «Логин» введите student, в «Новый пароль» — свой учебный пароль. В выпадающем списке справа выберите user.
  4. Нажмите «Сохранить». Ожидается сообщение «Пользователь сохранён» и новая строка student в таблице. Если такой логин уже есть, программа сообщит об этом — выберите другой.

Изменение пользователя: сначала выбрать строку

  1. Выберите строку student. Убедитесь, что в нижнем поле «Логин» появился именно student.
  2. Измените нужное поле. Оставьте «Новый пароль» пустым, если пароль менять не требуется.
  3. Нажмите «Сохранить» и проверьте строку в таблице. После сохранения редактор очищается — перед следующим изменением выберите пользователя заново.

Разблокировка: выбрать пользователя и поставить флажок

  1. Для проверки блокируйте только тестового student, не единственного администратора. Закройте главное окно, введите логин student и трижды отправьте неправильный пароль или несобранный пазл.
  2. Войдите администратором и откройте «Пользователи». Найдите student: в is_locked должен стоять флажок.
  3. Выберите эту строку. Проверьте логин внизу. Поставьте «Снять блокировку» и нажмите «Сохранить».
  4. В строке student ожидаются failed_attempts = 0 и снятый флажок is_locked. Закройте главное окно и проверьте вход student с правильным паролем и собранным пазлом.

Обычный пользователь: проверить доступ

  1. После входа student должны быть доступны «Заказчики» и «Стоимость заказов».
  2. Вкладки «Пользователи» и кнопки импорта быть не должно. Эти действия доступны только администратору.
  3. Чтобы выйти из рабочего окна, нажмите его крестик справа вверху. Откроется форма входа с очищенным паролем и перемешанным пазлом.
