Создайте отдельную пустую базу для готового примера. Так можно сравнить структуру, импорт и связи со своей работой.

1. Подготовьте файлы примера

Скачайте полный пример {{stackLabel}} кнопкой в начале раздела «Примеры проектов», распакуйте весь архив. Откройте examples/{{stack}}/Sql. Работайте с файлами этого стека.

2. Создайте структуру

В phpMyAdmin создайте отдельную базу с utf8mb4_bin, выберите её → Импорт → 01-schema.sql → Вперёд.

В pgAdmin создайте отдельную базу → Query Tool → Open File → 01-schema.sql → Execute. Таблицы появятся в public.

Ожидается 11 таблиц. Если база уже содержит таблицы примера, не выполняйте файл повторно.

3. Загрузите заказчиков и учебные записи

Выполните 02-customers.sql, затем 03-demo.sql по одному разу. Первый переносит шесть исходных заказчиков, второй добавляет данные для расчёта и учётные записи для запуска приложения.

4. Сверьте с собственной базой

Откройте структуру каждой таблицы и сравните типы, PK, FK, UNIQUE и CHECK. В counterparty должно быть шесть записей; коды сохраняют ведущие нули. Отличающееся имя таблицы в вашей работе допустимо, если модель сохраняет все данные и связи.
