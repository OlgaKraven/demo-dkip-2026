Здесь запускаем готовый исходный проект. Для создания своей программы откройте «Учиться и выполнять» → «Разбор» → модуль 4.

1. Скачайте проект

Скачать проект для {{stackLabel}}

  1. Скачайте архив и распакуйте целиком в свою папку.
  2. Откройте папку examples, затем {{stack}}. Найдите Polesie.csproj.
  3. Не перемещайте отдельные файлы: папка shared должна остаться рядом.

Для запуска нужны Windows, .NET Framework 4.8, Visual Studio и сервер {{stackLabel}}.

2. Откройте исходный проект в Visual Studio

  1. Скачайте полный пример {{stackLabel}} в начале раздела «Примеры проектов» и распакуйте весь ZIP.
  2. Откройте examples/{{stack}}/Polesie.csproj в Visual Studio. Не открывайте проект внутри архива. Соседняя папка shared должна остаться на месте.
  3. Разверните отдельную учебную базу по готовому примеру модуля 2.

3. Выполните сборку и настройте соединение

  1. В Visual Studio выберите «Сборка» → «Собрать решение». Дождитесь сообщения об успешной сборке. Если пакеты не восстановились, откройте управление NuGet и восстановите зависимости.
  2. В папке проекта появится bin/Debug. Там лежат exe, библиотеки, Assets и Sql.
  3. Откройте Data/Db.cs. Найдите строку ConnectionString. Замените значения адреса, порта, базы, имени пользователя и пароля на данные своего сервера. Нажмите Ctrl+S и снова «Сборка → Собрать решение».
  4. Впишите пользователя и пароль сервера базы. Проверьте имя своей базы и порт. Не вводите сюда пароль пользователя admin из таблицы users.
  5. Убедитесь, что скрипты 01-schema.sql, 02-customers.sql и 03-demo.sql уже выполнены. Нажмите F5.

В Db.cs меняйте только значения после знаков «=», сохраняя точки с запятой. Для MySQL используется User ID, для PostgreSQL — Username. Укажите порт своего сервера: он отображается в настройках подключения.

Настройки находятся в Db.cs и попадают в программу при сборке. При переносе на другую машину измените эту строку и пересоберите проект. Для экзамена используйте учебную учётную запись базы, выданную на площадке.

4. Выполните первый вход

Введите admin и DemoAdmin!2026. Посмотрите на изображение слева. Справа нажмите сначала один фрагмент, затем другой — они поменяются местами. Повторяйте, пока справа не получится тот же рисунок. Только после этого нажмите «Войти».

Появится сообщение «Вы успешно авторизовались», затем окно со вкладками. Учётная запись user / DemoUser!2026 открывает только заказчиков и стоимость. Вкладка пользователей доступна администратору.

5. Откройте формы в конструкторе

В обозревателе решений найдите UI/LoginForm.cs или UI/MainForm.cs → «Просмотреть конструктор» (Shift+F7). Выбирайте элемент и нажимайте F4, чтобы сопоставить свойства со своей формой. F7 открывает обработчики.

6. Проверьте экраны на данных

Откройте «Заказчики»: таблица должна показывать записи из базы. Перейдите на «Стоимость заказов»: значения должны совпадать с запросом из модуля 3. Вернитесь на «Пользователи» под admin и проверьте редактор выбранной строки.

Импорт JSON разобран в модуле 2, в дополнительном способе через приложение.

7. Проверьте роли

Войдите как user / DemoUser!2026: вкладки управления пользователями быть не должно. После закрытия рабочего окна вернитесь ко входу и войдите как admin / DemoAdmin!2026. Откройте пользователей и сравните доступные действия.
