Готовый запрос работает с учебными записями из примера модуля 2. Его результаты можно воспроизвести и сравнить с ручным расчётом.

1. Подготовьте учебную базу

В отдельной базе выполните файлы 01-schema.sql, 02-customers.sql и 03-demo.sql выбранного стека. Если уже делали это в примере модуля 2, используйте ту же базу.

2. Откройте и выполните запрос

Откройте Sql/04-cost.sql в SQL phpMyAdmin или Query Tool pgAdmin. Выполните целиком.

3. Сравните результат

Сначала сопоставьте результат со своим ручным расчётом. Затем проверьте изменение даты заказа на дату после изменения цены, отсутствие цены и пустой заказ в отдельной учебной копии данных. Новая цена должна применяться только начиная с даты её действия; отсутствующая цена не должна превращаться в нулевую стоимость.

4. Найдите причину расхождения

Если результаты отличаются, сравните количества заказа, выход спецификации, нормы и даты цен. Значения 371,00, 126,45 и 183,95 относятся только к учебным данным этого примера; для своих данных получите собственную контрольную сумму.
