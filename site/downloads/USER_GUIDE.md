# Как пользоваться проектом «ДЭ 2026»

## Четыре раздела

- **Учиться и выполнять** — разбор по одному шагу, тренировка и пробный экзамен. Кнопки «Назад» и «Далее» ведут по действиям; содержание позволяет перейти сразу к нужному шагу. «Показать все шаги» раскрывает весь материал.
- **Работа в программах** — отдельные справки по phpMyAdmin, SQL, Visual Studio и pgAdmin. Положение сохраняется для каждой инструкции. Снимки открываются крупнее нажатием.
- **Критерии экзамена** — семь официальных критериев, суммарно 50 баллов. Они относятся ко всей работе, а не повторяются как баллы каждого модуля.
- **Преподавателю** — презентации и профиль преподавателя.

## Справка phpMyAdmin и SQL

Снимки сделаны в phpMyAdmin 5.2.1 с MariaDB 10.4.32 из XAMPP. Учебная база — rassvet_demo_2026: 11 таблиц и 49 полей. Первая таблица создана вручную, остальные — по SQL проекта. В дизайнере сохранена страница «Полесье — учебная схема» с разнесёнными таблицами.

После создания базы инструкция SQL проводит через SELECT, JOIN, ручной расчёт, итоговый запрос и сохранение файла. На данных 02-customers.sql и 03-demo.sql проверены суммы 371,00; 126,45; 183,95. Для собственных данных итоги могут отличаться. Эти данные не являются экзаменационным решением студента.

Справка Visual Studio описывает Windows Forms на .NET Framework 4.8 — ту же платформу, что использует готовый проект. Добавлены реальные снимки выбора шаблона, настройки проекта, конструктора, свойства пароля, обработчика, сборки и запущенной формы. В конце инструкции скачивается исходный проект первой формы. Новые снимки PostgreSQL не создавались.

Справочные источники: [документация phpMyAdmin](https://docs.phpmyadmin.net/en/release_5_2_0/faq.html#how-can-i-produce-a-pdf-schema-of-my-database), [конструктор Windows Forms](https://learn.microsoft.com/en-us/visualstudio/designers/windows-forms-designer-overview?view=visualstudio).

## Гайды внутри разделов и навигация по ER

Кроме общего тура, доступны «Гид по разбору», «Гид по схеме», «Гид по практике» и «Гид по файлам». В презентации есть кнопка «Гид». Инструкции объясняют элементы текущего блока; тренировочный таймер они не запускают. Escape закрывает подсказку, повторное нажатие закрывает окно справки.

При пошаговом построении ER область схемы автоматически перемещается к добавленной таблице или полю. «К текущему элементу» возвращает к нему в масштабе 100%. «По ширине» подбирает масштаб для ширины области; «Вся схема» показывает общий план. В общем плане нажмите таблицу, чтобы перейти к чтению. Таблицы располагаются автоматически по связям; линии обходят их внутреннюю область. Кратности 1/N видны у концов линий; уникальная спецификация обозначена 0..1.

Верх справки уплотнён, подробные правила находятся под «Как читать схему». Источник показывается один раз, первым выделенным блоком, с адресом ячейки Excel или свойством JSON. Решения модели, которых нет в исходных файлах, отмечены отдельно.

## Перед занятием

1. Откройте «Преподавателю» → «Настройка преподавателя».
2. Заполните ФИО, должность, кафедру / подразделение и . Все поля необязательны.
3. При необходимости добавьте полный адрес папки материалов (`https://…`). Кнопка открывает эту папку в новой вкладке, а не загружает файлы на сайт. Доступ к папке задаётся в вашем хранилище.
4. Нажмите «Сохранить настройки». Данные появятся в разделе преподавателя и на титульных слайдах.

Настройки сохраняются только в этом браузере и не меняют сайт у других пользователей. «Скачать данные» экспортирует профиль в JSON. На другом устройстве нажмите «Загрузить данные», проверьте поля и сохраните их. Импорт поддерживает файлы профиля этого проекта версии 1, а не файлы курса или сценарии заметок лекционного шаблона.

## Разбор элементов проекта

В режиме «Разбор» выберите модуль M1–M5 и СУБД: MySQL или PostgreSQL. Разбор объясняет создание собственного результата. Отдельный раздел «Примеры проектов» содержит архивы и инструкции запуска готового решения. Гид по разбору расположен рядом с «Выберите модуль»; в переключателе режимов кнопок гида нет.

Название файла раскрывает исходный код. Ссылка рядом позволяет скачать его как текст. Полный проект скачивается в начале раздела «Примеры проектов». При переключении СУБД меняются SQL и параметры подключения; общая C#-логика остаётся одинаковой.

## Всё приложение по этапам

Модуль 4 и справка Visual Studio содержат 30 согласованных шагов: база, классы, компоненты LoginForm и трёх вкладок MainForm, свойства, полный код файлов, привязка Click/CellEnter и проверки. В таблицах указаны (Name), родитель и свойства. Реальные снимки конструктора показывают раскладку и привязанные события.

## Презентация разбора

Откройте «Преподавателю», выберите модуль, СУБД и вид разбора, затем нажмите «Открыть презентацию». Презентация соответствует выбранному модулю, СУБД и виду разбора.

Последовательность: титул с преподавателем → материалы → карта шагов → элементы разбора → вопросы аудитории. Смысловые блоки исходного текста распределены по слайдам. Таблицы разделены на группы до трёх строк, списки — на короткие части, а код — на фрагменты до 14 строк. У фрагмента указаны файл и номера строк. Заголовки таблиц повторяются, нумерация списков продолжается. Полные файлы можно скачать по ссылкам; на маленьком экране доступна прокрутка.

| Управление | Действие |
| --- | --- |
| Назад / Вперёд | Предыдущий / следующий слайд |
| ← / →, Page Up / Page Down | Перелистывание |
| Пробел | Следующий слайд |
| Home / End | Первый / последний слайд |
| Содержание | Список всех слайдов и переход к выбранному |
| На весь экран | Полноэкранный показ, если его разрешает браузер |
| К материалам преподавателя / Esc | Закрытие презентации; Esc сначала может выйти из полного экрана |

На кнопках, ссылках и полях ввода клавиатура сохраняет обычное действие. Для перелистывания нажмите на текст слайда. Позиция сохраняется отдельно для модуля, СУБД, редакции курса и вида разбора. В разборе и презентации таймера нет. Он доступен только в тренировке и пробном экзамене.

## Светлая и тёмная темы

Кнопка с луной / солнцем в верхнем меню или в презентации меняет оформление сайта и слайдов. При наведении появляется подсказка «Включить тёмную тему» / «Включить светлую тему». Размер и оформление кнопки перенесены из лекционного шаблона. Выбор сохраняется после перезагрузки. При первом открытии применяется тема устройства. Изображения и снимки окон сохраняют исходные цвета.

## Тренировка и пробный экзамен

«Моя тренировка» позволяет выбрать задание опубликованного образца, скачать исходники, поставить таймер на паузу, открыть подсказки и отметить самопроверку.

«Пробный экзамен» содержит V01–V30. Выберите номер по списку группы, подготовьте материалы и программы, отметьте три пункта готовности и начните. Общий лимит — 150 минут, паузы нет. Переключение разделов и перезагрузка страницы не останавливают время. После завершения скачайте протокол до начала новой попытки.

Сайт не читает решения, не выставляет оценки и не отправляет работу преподавателю. SQL, C#, PDF и другие результаты необходимо отдельно сохранять в папку сдачи.

## Запуск C#-примеров

Нужны Windows, Visual Studio с компонентом «Разработка классических приложений .NET», .NET Framework 4.8 и выбранная СУБД. WinForms не запускается нативно на macOS.

Скачайте полный пример, распакуйте его с сохранением структуры папок, откройте `Polesie.csproj`. В новой пустой базе выполните `Sql/01-schema.sql`, `02-customers.sql`, `03-demo.sql`. В `Data/Db.cs` измените `ConnectionString` под свой сервер, сохраните и соберите проект. Проверьте порт: он может отличаться от примера. Подробная инструкция и учебные данные входа находятся в README архива.

## Обслуживание сайта

Нужен Node.js 22+. В корне проекта выполните:

```sh
npm run build
npm test
npm run preview
```

Откройте адрес сервера, обычно `http://127.0.0.1:4190/`. Исходный интерфейс находится в `src/`, тексты разборов — в `lessons/`, данные курса — в `content/is.json`. Готовый сайт создаётся в `site/`. Правки в `site/` будут заменены при следующей сборке.

Данные преподавателя и позиция слайдов находятся в браузере, а не в исходниках. Очистка данных браузера может их удалить. Экспортируйте профиль перед переносом. Если хранилище недоступно, изменения остаются в памяти текущей вкладки до её закрытия.

Презентационный интерфейс и настройка перед занятием адаптированы по пользовательскому шаблону [2026-lecture-shablone](https://github.com/OlgaKraven/2026-lecture-shablone). В этом проекте используется одно окно показа; редактор лекционного курса и синхронизация двух окон сюда не переносились.
# Интерактивная справка ER и тур по сайту

Кнопка «Тур по сайту» в верхнем меню запускает добровольное знакомство с интерфейсом. Рамка выделяет текущий элемент, подсказка объясняет его назначение. Доступны «Назад», «Далее», «Завершить» и выход по Escape. Тур можно запустить повторно; таймеры и результаты он не изменяет.

В разборах модулей 1 и 2 кнопка «Справка: построить ER-схему» открывает последовательное построение всех 11 таблиц. Поля добавляются по одному, связи появляются после обоих концов. Этап сохраняется локально в браузере. В режиме «Готовая схема» можно выбрать любое поле или связь. Список этапов позволяет перейти к нужному месту.

Каждое поле сопровождается источником (файл, лист и ячейки Excel либо свойство JSON) или пометкой «Решение модели». Телефон и код контрагента берутся из «Заказчики.json». Пример ООО «Ассоль» — шестая запись. Ключ addres сопоставляется с address. Дата действия цены в исходном Excel отсутствует; расхождение цен расчёта и прайс-листа объяснено отдельно.

Русские подписи помогают читать схему. Английские имена соответствуют SQL проекта. Для своей реализации выбирайте единый перевод или транслитерацию во всей базе и программе. Завершающий этап содержит ссылки на SQL и ER PDF; полная настройка базы разобрана в модуле 2.

## Просмотр файлов и сохранённый расчёт

В «Разборе» исходные файлы находятся в свёрнутом блоке. «Просмотр» открывает Excel с листами и адресами ячеек, JSON, PDF, SQL или HTML поверх страницы. Excel-представление подготовлено из оригинальных книг и предназначено для чтения. После изменения книг его нужно обновить скриптом `scripts/prepare-file-previews.py` перед сборкой сайта. Исходные книги не изменяются. «Скачать» сохраняет оригинал. Изображения увеличиваются в этом же окне: доступны масштаб, прокрутка и возврат по Esc.

В «Моей тренировке» документы также можно читать на сайте. Кнопки «Гид» стоят рядом с названиями тренировки и пробного экзамена. Они объясняют режим и не запускают отсчёт.

Материалы преподавателя: https://disk.yandex.ru/d/h3QUsGWcrr_tsQ . Адрес установлен в настройках по умолчанию. Поле учебного заведения удалено. Ссылка на официальный ZIP в баннере сохранена.

В учебной MySQL/MariaDB-базе запрос сохранён как `calculate_order_material_costs()`. Вызов: `CALL calculate_order_material_costs();`. Архив `downloads/polesie-mysql-database.zip` содержит выгрузку структуры, данных и процедуры. Импорт проверен в новой пустой базе: 11 таблиц, 49 полей, суммы 371.00 / 126.45 / 183.95. Отдельный `05-cost-procedure.sql` нужен только для добавления процедуры в свою базу.

Презентации группируют связанный текст, показывают до 5 строк таблицы или 17 строк кода за слайд. Полный код открывается отдельной кнопкой поверх презентации; копирование включает весь файл. Позиции слайдов сброшены один раз при переходе на новую разбивку.

По умолчанию презентация открывает краткий показ: 11–16 слайдов с целями, основными действиями и проверкой. Кнопка «Подробный разбор» переключает на расширенное содержание. Длинный файл вводится одним слайдом; весь код доступен в просмотрщике. Позиции краткого и подробного показа сохраняются отдельно.
