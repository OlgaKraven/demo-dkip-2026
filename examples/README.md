# Полесье · C# Windows Forms · 2026

1. Распакуйте архив полностью. Откройте `examples/mysql/Polesie.csproj` или `examples/postgresql/Polesie.csproj` в Visual Studio с компонентом «Разработка классических приложений .NET».
2. Создайте новую пустую базу `rassvet_demo_2026`. MySQL: utf8mb4; PostgreSQL: схема public.
3. Выполните один раз файлы `Sql/01-schema.sql`, `02-customers.sql`, `03-demo.sql` выбранного проекта. Скрипты не удаляют существующие базы и таблицы.
4. Соберите проект. Платформа — .NET Framework 4.8; драйверы и компилятор восстановятся через NuGet. Подготовьте зависимости до работы без интернета.
5. В `examples/shared/Data/Db.cs` измените `ConnectionString`: адрес, порт, база, пользователь и пароль своего сервера. Сохраните файл и пересоберите проект. Учётная запись базы отличается от пользователя приложения.
6. Запустите exe, соберите пазл и войдите: `admin / DemoAdmin!2026` или `user / DemoUser!2026`. Это только учебные учётные записи.
7. Для импорта используйте исходный `Заказчики.json`. Повторный импорт обновляет записи по id.

Обе сборки используют исходники в `examples/shared`. Сохраните взаимное расположение папок. У LoginForm и MainForm есть файлы Designer.cs: в Visual Studio выберите основной файл формы → «Просмотреть конструктор» (Shift+F7), код обработчиков — F7. Раскладка находится в InitializeComponent; работа с базой выполняется при запуске приложения. Панель puzzleHost заполняется пазлом при запуске. Запрос для сдачи лежит в `Sql/04-cost.sql`; приложение выполняет такой же запрос из `MainForm.cs`, результаты: 371,00; 126,45; 183,95.

В архиве есть ER.pdf, пример документации и таблица тестов. Полный пошаговый разбор доступен на сайте курса. В модуле 4 разбираются все основные классы, параметры SQL, состояния пазла и счётчик ошибок.

Драйверы: MySqlConnector 2.4.0, Npgsql 4.1.14. Для локального учебного соединения заполните настройки примера; параметры TLS для удалённого сервера задаются по его конфигурации. Реальные реквизиты подключения не публикуются.

## Код и проверка

Program.cs запускает форму. Designer.cs создаётся визуальным конструктором. В Models — отдельный класс на каждую сущность; Db.Table, Db.Count и Db.Execute объединяют повторяющуюся работу с базой. Проверки и создание снимков вынесены в tests/app основного репозитория и не включены в учебный архив.

Импорт разделён на два коротких этапа: проверка всего JSON до подключения к базе и сохранение проверенных записей одной транзакцией. Проверки полей во втором цикле не дублируются. После записи обновляется экран; ошибка обновления не означает, что сохранение отменено. Проверки ролей, паролей и блокировки сохранены. Уменьшать код за счёт этих проверок или объединять отдельные классы сущностей не требуется.
