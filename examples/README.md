# Полесье · C# Windows Forms · 2026

1. Распакуйте архив полностью. Откройте `examples/mysql/Polesie.csproj` или `examples/postgresql/Polesie.csproj` в Visual Studio с компонентом «Разработка классических приложений .NET».
2. Создайте новую пустую базу `rassvet_demo_2026`. MySQL: utf8mb4; PostgreSQL: схема public.
3. Выполните один раз файлы `Sql/01-schema.sql`, `02-customers.sql`, `03-demo.sql` выбранного проекта. Скрипты не удаляют существующие базы и таблицы.
4. Соберите проект. Платформа — .NET Framework 4.8; драйверы и компилятор восстановятся через NuGet. Подготовьте зависимости до работы без интернета.
5. В `bin/Debug` скопируйте `connection.example.txt` в `connection.local.txt` и впишите пользователя, пароль, порт своего сервера. Учётная запись базы отличается от пользователя приложения.
6. Запустите exe, соберите пазл и войдите: `admin / DemoAdmin!2026` или `user / DemoUser!2026`. Это только учебные учётные записи.
7. Для импорта используйте исходный `Заказчики.json`. Повторный импорт обновляет записи по id.

Обе сборки используют исходники в `examples/shared`. Сохраните взаимное расположение папок. Дизайн форм создаётся кодом в UI, поэтому для просмотра запустите программу. SQL запрос стоимости лежит в `Sql/04-cost.sql`, результаты: 371,00; 126,45; 183,95.

В архиве есть ER.pdf, пример документации и таблица тестов. Полный пошаговый разбор доступен на сайте курса. В модуле 4 разбираются все основные классы, параметры SQL, состояния пазла и счётчик ошибок.

Драйверы: MySqlConnector 2.4.0, Npgsql 4.1.14. Для локального учебного соединения заполните настройки примера; параметры TLS для удалённого сервера задаются по его конфигурации. Реальные реквизиты подключения не публикуются.
