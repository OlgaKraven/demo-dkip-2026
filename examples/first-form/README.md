# Первая форма Windows Forms

Исходный проект пошаговой справки Visual Studio. C#, .NET Framework 4.8.

1. Откройте `PolesieTraining.csproj` в Visual Studio с компонентом разработки классических приложений .NET.
2. Откройте Form1.cs в конструкторе (Shift+F7). Здесь два поля и кнопка.
3. Сравните свойства `(Name)`, `Text`, `UseSystemPasswordChar` со справкой сайта.
4. Двойной щелчок по кнопке открывает обработчик `enter_Click`.
5. Соберите проект Ctrl+Shift+B и запустите F5.

Пустой логин вызывает «Введите логин». Непустой — сообщение о работе кнопки. Подключения к базе и настоящей авторизации в этом первом упражнении ещё нет. Продолжение с базой, ролями и четырьмя формами находится в модуле 4 сайта.

Проверено в Visual Studio 2026: сборка без ошибок, запуск и обработчик кнопки.
