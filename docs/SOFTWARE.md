# Программное обеспечение учебного проекта

Проверено 14 сентября 2026 года. Для нового учебного стенда выбран комплект PostgreSQL + pgAdmin + Npgsql. Альтернативный проект MySQL сохранён, чтобы не менять заданную предметную область и доступные маршруты.

- PostgreSQL: [PostgreSQL License](https://www.postgresql.org/about/licence/).
- pgAdmin: [PostgreSQL License](https://www.pgadmin.org/licence/).
- Npgsql: [PostgreSQL License](https://www.npgsql.org/).
- MySqlConnector: [MIT](https://github.com/mysql-net/MySqlConnector/blob/master/LICENSE).

Эти открытые лицензии разрешают использование при соблюдении их условий и не содержат отдельного запрета для РФ или стран СНГ. Это не универсальное заключение о законодательстве всех стран, санкционных ограничениях, доступности поставок или лицензии Windows и Visual Studio. Организатор проверяет допустимость установленного ПО для своей организации и площадки. Не используйте нелицензионные сборки и средства обхода активации.

В примерах закреплены Npgsql 4.1.14 и MySqlConnector 2.4.0 для .NET Framework 4.8. Это совместимость учебной сборки, а не рекомендация для нового промышленного сервиса. Пароли обрабатываются встроенным System.Security.Cryptography: PBKDF2-HMAC-SHA256, случайная соль, 100000 итераций. Отдельный пакет хэширования не нужен. Пример не заявляет соответствие требованиям сертифицированной криптографии.

Подключение задаётся в существующем Data/Db.cs, поле ConnectionString. После изменения проект пересобирается. Отдельного файла подключения нет. Реальные пароли сервера не публикуйте вместе с исходниками: для сдачи используйте только реквизиты учебной базы, согласованные с организатором. SQL-файлы — результаты модулей и средства создания БД, а не дополнительные файлы настройки приложения.

На этом Mac проверены сборки обоих проектов и по 23 проверки бизнес-логики на XAMPP MariaDB и PostgreSQL 16: расчёты, хэши, роли, блокировка, разблокировка, импорт и отклонение ошибочных файлов без изменения данных. Проверки выполнены в отдельных временных базах. MySQL-совместимый проект проверен здесь на MariaDB, не на MySQL Server. Полноценный запуск окон WinForms и конструктора Visual Studio требует Windows и остаётся отдельной проверкой на экзаменационном стенде. Сборка legacy-проекта через dotnet на macOS потребовала временных ссылок на восстановленные пакеты; они не добавлены в студенческий проект.
