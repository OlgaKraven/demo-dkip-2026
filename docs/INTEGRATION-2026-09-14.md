# Интеграция упрощённого C# · 14 сентября 2026

## Что изменено

- Обе версии приложения используют обновлённые исходники examples/shared.
- ImportCustomers проверяет весь JSON до открытия соединения. Повторная проверка тех же id/name в цикле записи удалена; проверка обязательных полей, типов, пустых значений и повторяющихся id сохранена.
- Убраны неиспользуемые using из обработчиков форм. Несколько команд не объединяются в одну строку ради сокращения кода.
- Сохранены параметризованные SQL-запросы, транзакции, проверка роли по базе, PBKDF2, блокировка после трёх ошибок и отдельные классы сущностей.
- Подключение задаётся в Data/Db.cs. Внешний текстовый файл настроек для запуска не требуется. После изменения подключения нужна повторная сборка.
- Разбор M2 объясняет последовательность проверки и записи; M4 отдельно объясняет сохранение данных и последующее обновление экрана. Встроенные фрагменты C# и архивы пересобраны из текущих исходников.
- В tests/app добавлен режим --logic-test: он пропускает создание окон. Обычный --test по-прежнему включает графические проверки.
- Публикация GitHub Pages устанавливает зависимости через npm ci перед сборкой и тестами.

## Повторение проверки на Windows

1. В Developer PowerShell for Visual Studio соберите tests/app/Checks.csproj через MSBuild с /restore и /p:DatabaseStack=mysql либо postgresql.
2. Используйте только отдельную пустую тестовую базу. Выполните в ней 01-schema.sql, 02-customers.sql и 03-demo.sql выбранной версии. Проверки изменяют данные, поэтому рабочая база не подходит.
3. Рядом с Polesie.Checks.exe должны быть приложение и все его DLL, папки Sql и Assets из соответствующей сборки.
4. Задайте для тестового процесса переменные DEMO_CONNECTION (строка подключения к тестовой базе) и DEMO_IMPORT_FILE (полный путь к исходному Заказчики.json). Эти переменные использует только тестовый запуск, не учебное приложение.
5. Запустите Polesie.Checks.exe --logic-test. Ожидается код завершения 0 и PASS: 43 checks в test-result.txt рядом с тестовой программой.
6. Для проверки окон используйте --test на Windows; он не проверен в текущем окружении. Дополнительно вручную проверьте конструктор форм, пазл, клавиатурную навигацию, выбор пользователя, изменение размеров и потерю соединения.

## Ограничения

Полный запуск WinForms и конструктор Visual Studio на Windows в этой проверке недоступны. Совместимость с настоящим MySQL Server здесь не проверялась — использовалась MariaDB. Исторические снимки окон не являются снимками новой сборки. В PostgreSQL-архиве оставлен CHANGE_ME: перед запуском задайте свои параметры в Db.cs и пересоберите; пароль сервера не публикуется.
