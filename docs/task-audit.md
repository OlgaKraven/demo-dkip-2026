# Проверка по заданию 2026

Проверен опубликованный базовый образец КОД 09.02.07-5-2026 и приложение «Требования к разработке.pdf». Баллы за отдельные действия не назначались.

| Требование | Реализация и проверка |
|---|---|
| M1: ER, атрибуты, PK/FK, 3НФ, PDF | Справочники отделены от шапок и строк документов; состав выделен отдельно; цены хранятся на дату. ER.pdf соответствует 11 таблицам SQL. |
| M2: таблицы, отношения, ограничения | На обеих СУБД развёрнута новая база; проверены PK, FK, UNIQUE и положительное количество. |
| M2: исходный JSON | Сверены все поля всех шести объектов: коды, названия, ИНН, адреса, телефоны и два признака. Повторный импорт не создаёт дубли; некорректный объект отменяет весь импорт. |
| M3: количество, норма, все материалы | Итоги 371,00 / 126,45 / 183,95; проверен выход партии, отсутствие цены и состава. Снимки C# из модуля запросов удалены. |
| M4: обязательные поля и сообщения | Проверены пустой логин и пароль, неизвестный логин, неверный пароль и одновременная ошибка пароля и пазла. Текст неправильных учётных данных соответствует условию. |
| M4: интерактивный пазл | Начальное и повторное перемешивание не дают собранную картинку; обмен фрагментов позволяет собрать её. |
| M4: три ошибки, блокировка и снятие | Счётчик хранится в БД; две неправильные проверки в одной попытке дают одно увеличение. Проверены третья ошибка, последующий отказ и разблокировка. |
| M4: роли и редактор | Обычный пользователь видит две вкладки; администратор — три. Сервис проверяет права. Проверены дубли, изменение логина и пароля, сохранение без изменения пароля и исчезнувшая запись. |
| Приложение: структура классов | Для каждой сущности есть отдельный небольшой класс Models. Раскладка в Designer.cs, действия в формах и Services, SQL-помощники в Db. |
| Приложение: интерфейс | Скрытие пароля, AcceptButton, MinimumSize, Dock таблицы проверены программно. Уточнён TabIndex: логин → пароль → пазл → кнопка. Макеты сохранены через WinForms Designer.cs; интерактивная работа самого Visual Studio Designer отдельно не подтверждена. |
| M5: назначение, методы, параметры | Обновлены описание классов и методы Db.Execute/Db.Count. Документ встроен в пример модуля 5 и доступен отдельно. |

## Упрощение

Из учебного проекта убраны Checks и инструменты снимков: теперь они в tests/app. Program.cs: 49 → 24 строки; Users.cs: 61 → 47; ImportCustomers.cs: 44 → 35; AuthService.cs: 52 → 50. Повторяющиеся команды сведены к Db.Count и Db.Execute. Транзакции, SQL-параметры и хэширование пароля сохранены.

Всего в examples/shared: 941 → 911 строк C#, включая автоматически задаваемую раскладку и добавленные девять классов сущностей. Раскладку создают в конструкторе; модели повторяют поля диаграммы. Заучивать служебные тесты и код создания снимков не требуется.

## Проверки

MSBuild: оба проекта и отдельный тестовый запуск собраны. По 52 проверки на MySQL 8.4.0 и PostgreSQL 18. Использованы отдельные тестовые базы audit_demo_2026, рабочие базы пользователя не изменялись. Результаты: docs/integration-results.json. Оценка эксперта и проверки на экзаменационной площадке этим не заменяются.
