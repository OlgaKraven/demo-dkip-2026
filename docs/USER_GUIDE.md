# Как пользоваться проектом «ДЭ 2026»

## Перед занятием

1. В верхнем меню откройте «Настройка перед занятием».
2. Заполните ФИО, должность, кафедру / подразделение и учебное заведение. Все поля необязательны.
3. При необходимости добавьте полный адрес папки материалов (`https://…`). Кнопка открывает эту папку в новой вкладке, а не загружает файлы на сайт. Доступ к папке задаётся в вашем хранилище.
4. Нажмите «Сохранить настройки». Данные появятся на главной странице и титульных слайдах.

Настройки сохраняются только в этом браузере и не меняют сайт у других пользователей. «Скачать данные» экспортирует профиль в JSON. На другом устройстве нажмите «Загрузить данные», проверьте поля и сохраните их. Импорт поддерживает файлы профиля этого проекта версии 1, а не файлы курса или сценарии заметок лекционного шаблона.

## Разбор элементов проекта

В режиме «Разбор» выберите модуль M1–M5 и СУБД: MySQL или PostgreSQL. Маршрут «Как сделать пошагово» объясняет создание собственного результата. «Как посмотреть готовый пример» показывает работу с готовым проектом.

Название файла раскрывает исходный код. Ссылка рядом позволяет скачать его как текст. Полный проект скачивается внизу страницы. При переключении СУБД меняются SQL и параметры подключения; общая C#-логика остаётся одинаковой.

## Презентация разбора

Нажмите «Презентация разбора» рядом с переключателями маршрута. Презентация соответствует выбранному модулю, СУБД и виду разбора.

Последовательность: титул с преподавателем → материалы → карта шагов → элементы разбора → вопросы аудитории. Смысловые блоки исходного текста распределены по слайдам. Таблицы разделены на группы до трёх строк, списки — на короткие части, а код — на фрагменты до 14 строк. У фрагмента указаны файл и номера строк. Заголовки таблиц повторяются, нумерация списков продолжается. Полные файлы можно скачать по ссылкам; на маленьком экране доступна прокрутка.

| Управление | Действие |
| --- | --- |
| Назад / Вперёд | Предыдущий / следующий слайд |
| ← / →, Page Up / Page Down | Перелистывание |
| Пробел | Следующий слайд |
| Home / End | Первый / последний слайд |
| Содержание | Список всех слайдов и переход к выбранному |
| На весь экран | Полноэкранный показ, если его разрешает браузер |
| К разбору / Esc | Закрытие презентации; Esc сначала может выйти из полного экрана |

На кнопках, ссылках и полях ввода клавиатура сохраняет обычное действие. Для перелистывания нажмите на текст слайда. Позиция сохраняется отдельно для модуля, СУБД, редакции курса и вида разбора. В разборе и презентации таймера нет. Он доступен только в тренировке и пробном экзамене.

## Светлая и тёмная темы

Кнопка с луной / солнцем в верхнем меню или в презентации меняет оформление сайта и слайдов. При наведении появляется подсказка «Включить тёмную тему» / «Включить светлую тему». Размер и оформление кнопки перенесены из лекционного шаблона. Выбор сохраняется после перезагрузки. При первом открытии применяется тема устройства. Изображения и снимки окон сохраняют исходные цвета.

## Тренировка и пробный экзамен

«Моя тренировка» позволяет выбрать задание опубликованного образца, скачать исходники, поставить таймер на паузу, открыть подсказки и отметить самопроверку.

«Пробный экзамен» содержит V01–V30. Выберите номер по списку группы, подготовьте материалы и программы, отметьте три пункта готовности и начните. Общий лимит — 150 минут, паузы нет. Переключение разделов и перезагрузка страницы не останавливают время. После завершения скачайте протокол до начала новой попытки.

Сайт не читает решения, не выставляет оценки и не отправляет работу преподавателю. SQL, C#, PDF и другие результаты необходимо отдельно сохранять в папку сдачи.

## Запуск C#-примеров

Нужны Windows, Visual Studio с компонентом «Разработка классических приложений .NET», .NET Framework 4.8 и выбранная СУБД. WinForms не запускается нативно на macOS.

Скачайте полный пример, распакуйте его с сохранением структуры папок, откройте `Polesie.csproj`. В новой пустой базе выполните `Sql/01-schema.sql`, `02-customers.sql`, `03-demo.sql`. В `Data/Db.cs` измените `ConnectionString` под свой сервер, сохраните и соберите проект. Проверьте порт: он может отличаться от примера. Подробная инструкция и учебные данные входа находятся в README архива.

## Обслуживание сайта

Нужен Node.js 22+. В корне проекта выполните:

```sh
npm run build
npm test
npm run preview
```

Откройте адрес сервера, обычно `http://127.0.0.1:4190/`. Исходный интерфейс находится в `src/`, тексты разборов — в `lessons/`, данные курса — в `content/is.json`. Готовый сайт создаётся в `site/`. Правки в `site/` будут заменены при следующей сборке.

Данные преподавателя и позиция слайдов находятся в браузере, а не в исходниках. Очистка данных браузера может их удалить. Экспортируйте профиль перед переносом. Если хранилище недоступно, изменения остаются в памяти текущей вкладки до её закрытия.

Презентационный интерфейс и настройка перед занятием адаптированы по пользовательскому шаблону [2026-lecture-shablone](https://github.com/OlgaKraven/2026-lecture-shablone). В этом проекте используется одно окно показа; редактор лекционного курса и синхронизация двух окон сюда не переносились.
